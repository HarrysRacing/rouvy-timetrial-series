Privacy Policy

Last updated: 2026

Data collected

This site accesses race event and activity data via the ROUVY API in order to compute and display race standings.

How data is used

Data is used solely for:

  • Computing race results and standings
  • Displaying event summaries

Data sharing

No data is sold or shared with third parties. Data is used only for the operation of this community race series site.

Third parties

This site interacts with the ROUVY API for retrieval of authorised race data.

Contact

For privacy concerns, contact the project maintainer via the repository or project contact email.
